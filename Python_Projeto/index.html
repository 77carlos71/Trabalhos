Sobre o Projeto

Veja abaixo um projeto desenvolvido em Python utilizando a biblioteca Flet, denominado "Pizzaria do Carlos". Este aplicativo é uma ferramenta de gestão para pizzarias, permitindo o cadastro e a visualização de clientes, pedidos e pizzas. O sistema também permite a exportação de dados para Excel, facilitando o gerenciamento e a organização das informações de forma prática e eficiente. Este projeto é o Trabalho de Conclusão de Curso do SENAC, onde são aplicados todos os conhecimentos adquiridos ao longo da formação.
